# ASCII Studio

Simple static web application to get high quality images of ASCII art using HTML canvas and the [canvas2image](https://github.com/hongru/canvas2image) library.

The "default art" can be found here: <https://www.asciiart.eu/art/7b24bf98d3e1d075>. It has been edited to not have the text.
The art in the favicon can be found here: <https://www.asciiart.eu/art/ead15d9f910decf5>, made by Donovan Baker.

## Functionality

- Paste text into the input area to create the canvas image.
- Click the "clear" button to clear all the text that was added to the input.
- Change the background color, text color, and margin settings to edit how the image will look.
- Click the "Save as PNG" button to download the canvas image as a PNG into your machine.

## Installation

The application is a live website. If you want a local copy into your machine, simply clone the repository and open `index.html` in a browser of your choice.
